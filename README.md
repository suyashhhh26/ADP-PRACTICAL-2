# 🎓 TechFest 2026 - College Event Website

A responsive College Event Website created using **HTML, CSS, and Bootstrap 5**.  
This project showcases a modern college event landing page with a responsive navbar, event highlights, and contact section.

---

## 🚀 Features

- ✅ Responsive Bootstrap Navbar
- ✅ Hero Section with Gradient Background
- ✅ Event Highlights Cards
- ✅ Contact Form
- ✅ Mobile Friendly Design
- ✅ Bootstrap 5 Classes Used
- ✅ Clean and Simple UI
